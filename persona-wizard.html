NovaPay copilot persona builder

Turn student research into a reusable persona prompt

Rosie and her friends can use this wizard to define one or more personas, then export a clean prompt for build work, review work, or both. The output is designed to paste into Copilot chats, issue notes, or lesson docs.

Wizard

1. Set the project context

Start with the feature and the teaching goal.

2. Describe the first persona

Capture the person, their context, and the problem they need solved.

3. Add more personas if needed

Multiple personas can be entered one by one and included in the same export.

4. Review and export

Use the generated text as the brief for build and review stages in Copilot.

Tip: the export is intentionally markdown-friendly so it can be pasted into Copilot chats, pull requests, or classroom notes.
