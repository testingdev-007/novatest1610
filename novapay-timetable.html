How the day works

📁

Work in GitHub

Use the Code tab to open files, read them, and make edits directly in the repo.

🤖

Use Copilot well

Ask clear questions in the repo or file view, then check the answer before keeping it.

🌐

Publish and view

After changes are saved, view the output in the browser and refresh to see the result.

🔁

Iterate

Make a small change, publish, refresh, test, and improve again.

Quick notes

  • Codespaces are not part of this workflow.
  • This is a browser-first workaround using GitHub.
  • Keep changes small so the published result is easy to check.
  • Use the timetable to stay on track through the day.
What if the page doesn't update straight away?
  • Wait a moment for the publish to finish.
  • Refresh the browser tab.
  • Check that the right file was changed.
  • Then test again.
